macOS Ports

Ham radio software that was Windows-only, rebuilt as native Mac apps.

Morse Runner

Port of Morse Runner 1.68 for Windows by Alex Shovkoplyas, VE3NEA

The classic CW contest simulator, rebuilt in Swift and AppKit with 1:1 parity: the same audio, simulated stations, scoring and layout.

  • macOS 15+
  • Apple Silicon & Intel
  • Swift

TX500 Utility

Mac replacement for Lab599's Windows TRXSettings and TRXMem

CAT control, all 100 memory channels, settings backup and restore, clock sync and firmware updates for the Lab599 Discovery TX-500.

  • macOS 26+
  • Apple Silicon
  • Swift

Radio & Station Apps

Original apps for gear that never had a good Mac option.

QK4

Remote control for the Elecraft K4 and KPA1500

Full K4 operation over your network: dual VFOs, GPU panadapter and waterfall, encrypted connection and stereo Opus audio.

  • macOS 14+
  • Windows 11
  • Raspberry Pi

QK-LP100A

For the TelePost LP-100A Digital Vector RF Wattmeter

Real-time power, SWR and impedance gauges, plus automated antenna sweeps with Hamlib rig control and a Smith chart.

  • Apple Silicon
